# Навигация постов, избранные статьи и печать

## Предыдущий и следующий пост

В футере каждого поста автоматически появляется хронологическая навигация.
**Предыдущий пост** — более старая публикация, **следующий пост** — более новая.
Поэтому у первой и последней статьи выводится только одна ссылка. Переходы не
выходят за пределы текущей локали.

Блок включён по умолчанию. Его можно переставить или убрать через `postFooter`:

```yaml
themeConfig:
  postFooter:
    - author
    - tags
    - navigation
    - similar
```

`navigation` и `similar` решают разные задачи: первый следует хронологии,
второй выбирает материалы по общим тегам.

Подписи настраиваются для каждой локали в `_site.yaml`:

```yaml
themeConfig:
  t:
    previousPost: Ранее
    nextPost: Далее
```

В собственном layout можно импортировать `PostNavigation` из
`vitepress-theme-neptu/components` и передать ему посты текущей локали.

## Избранные посты (`featured`)

Добавьте во frontmatter нужной статьи:

```yaml
---
title: Статья, с которой стоит начать
date: 2026-08-01
featured: true
---
```

Флаг не меняет порядок свежих постов, архивов, фидов или похожих материалов.
Он только включает запись в явно размещённую редакционную подборку. Добавьте
её на главную страницу в нужном месте:

```md
<script setup>
import { HomeFeaturedPosts } from 'vitepress-theme-neptu/components'
</script>

<HomeFeaturedPosts :max-posts="3" />
```

Заголовок можно переопределить через prop `header`; иначе используется перевод
`t.featuredPosts`. Внутри подборки записи идут от новых к старым.

## Лента recent или popular вместо лендинга на главной

По умолчанию главная страница (`layout: home`) — это лендинг с hero-блоком,
опциональным параллакс-фоном и настраиваемыми секциями, но **без сайдбара**.

Если нужна обычная лента постов (с сайдбаром, aside и стандартным оформлением),
замените `layout: home` на `layout: util` в файле `index.md` и вставьте тот же
компонент, что используется в шаблоне `recent/[page].md`:

```md
---
layout: util
---

<script setup>
import { RecentList } from 'vitepress-theme-neptu/components'
</script>

<RecentList :curPage="1" />
```

Для популярных постов замените `RecentList` на `PopularPostsList` (требуется
`popularPosts.enabled` в `.vitepress/config.ts`).

### Отличия от шаблона списка

- **`paths.js` не нужен.** `index.md` — статическая страница, а не динамический
  маршрут `[page]`, поэтому `params.page` равен `undefined` и defaults to `1`.
- **Уберите `robots: noindex`.** Шаблоны списков ставят `noindex`, чтобы
  поисковики не индексировали дубли страниц пагинации. Главная страница,
  наоборот, должна индексироваться — удалите блок `head`.
- **Пагинация.** `RecentList` и `PopularPostsList` вычисляют базовый URL
  пагинации из текущего route. На главной (`/ru/`) ссылки будут указывать на
  `/ru/1`, `/ru/2` — таких страниц не существует. Поэтому главная работает как
  первая страница ленты; для полной пагинации добавьте ссылки на `recent/1`
  или `popular/1` в навигацию или сайдбар.

## Печать

Настройка не нужна. При печати тема скрывает сайдбар, верхнюю навигацию, футер
сайта, интерактивные блоки под статьёй и кнопки возврата наверх. Статья занимает
всю доступную ширину, длинный код переносится, крупные медиа-блоки не разрываются,
а у внешних ссылок печатается их адрес.

Чтобы скрыть собственный элемент, добавьте `data-print-ignore`:

```html
<aside data-print-ignore>Этот блок нужен только на экране.</aside>
```
