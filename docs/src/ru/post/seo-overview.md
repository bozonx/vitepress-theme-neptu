Это вводная страница продвинутого раздела. Тема закрывает техническое SEO за вас:
достаточно задать `siteUrl` — и при сборке появляется всё нужное. Здесь — общая
карта, а детали каждой темы в отдельных постах ниже.

## Что генерируется автоматически

При сборке для всего сайта создаётся:

| Механизм | Что делает | Подробнее |
| --- | --- | --- |
| **sitemap.xml** | карта сайта из `siteUrl`, без `noindex`-страниц | [Ленты и поиск](seo-feeds-search) |
| **robots.txt** | со ссылкой на sitemap | [Ленты и поиск](seo-feeds-search) |
| **RSS / Atom / JSON** | ленты для каждой локали | [Ленты и поиск](seo-feeds-search) |
| **Open Graph + Twitter card** | превью для соцсетей на каждой странице | [Ленты и поиск](seo-feeds-search) |
| **JSON-LD** | микроразметка `Article` для постов | [Микроразметка JSON-LD](json-ld) |
| **canonical** | ссылка на первоисточник страницы | [Canonical и кросспостинг](canonical-crosspost) |
| **hreflang** | связь переведённых версий | [Локализация и hreflang](i18n-hreflang) |

## Единственная обязательная настройка

Всё SEO опирается на абсолютный адрес сайта. Задайте его в коде — без завершающего слэша:

```ts
// .vitepress/config.ts
siteUrl: 'https://myblog.org'
```

Без `siteUrl` тема выведет предупреждение при сборке, а canonical, sitemap, RSS и
OG будут генерировать неполные ссылки.

## Как отключить любую функцию

Все SEO-функции включены по умолчанию. Выключаются они в двух местах:

```yaml
# Глобально — src/site.yaml
themeConfig:
  seo:
    og: true
    jsonLd: true
    hreflang: true
    canonical: true
    rss: true
```

```yaml
# Для одной страницы — во frontmatter поста (переопределяет глобальное)
seo:
  jsonLd: false
```
