Пост — это обычный Markdown-файл в папке `src/<локаль>/post/`. Имя файла
становится адресом страницы: `post/my-first-post.md` → `/ru/post/my-first-post`.

## Минимальный пост

Создайте файл `src/ru/post/my-first-post.md`:

```md
---
date: 2025-07-24T10:00:00Z
authorId: maria-editor
---

# Привет, мир

Это мой первый пост. Обычный **Markdown** — тема сама покажет его в списках,
лентах и поиске.
```

Обязательных полей всего два:

- **`date`** — дата публикации в формате ISO. По ней строятся сортировка, архив
  и ленты. Указывайте время, если в один день выходит несколько постов.
- **`authorId`** — идентификатор автора из [`_authors.yaml`](../authors/).

Заголовок тема берёт из первого `#` в тексте. Отдельное поле `title` нужно
только чтобы переопределить его (например, для более длинного `<title>` вкладки).

## Частые поля

Когда основа работает, к посту добавляют по мере надобности:

```md
---
title: Заголовок для вкладки и SEO
description: Краткое описание для поисковиков и превью в списках.
date: 2025-07-24T10:00:00Z
authorId: maria-editor
descrAsPreview: true
tags:
  - guide
  - release
cover: /img/my-cover.jpg
coverAlt: Описание обложки для доступности
---
```

- **`description`** — мета-описание и, при `descrAsPreview: true`, текст карточки в списках.
- **`tags`** — теги; по ним строятся страницы тегов и блок «похожие посты».
- **`cover`** — обложка поста (локальный путь или внешний URL).

Полный перечень полей с живыми примерами — в [посте со всеми полями
frontmatter](full-featured). А управление обложками, превью и медиа разбирается
в следующих статьях раздела «Контент».

## Куда положить страницу без даты

Если это не статья, а постоянная страница (например, «О блоге»), положите её в
`src/<локаль>/page/` с `layout: page` — тогда она не попадёт в ленты и архив.
Пример — [демо-страница «О блоге»](../page/about).
