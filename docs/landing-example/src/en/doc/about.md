# About Neptu Landing

**Neptu Landing** is a landing page theme for VitePress, built on top of the Neptu blog theme.

## Features

- **SEO-first**: Built-in Open Graph, JSON-LD, canonical links, hreflang, and sitemap
- **i18n-ready**: Multi-locale support with YAML-based config and template substitution
- **Fully typed**: Complete TypeScript support with proper types for config, layouts, and components
- **Tailwind CSS**: Built-in support via @tailwindcss/vite
- **Pagefind Search**: Local site search with minimal setup

## Getting started

Check the [GitHub repository](https://github.com/bozonx/vitepress-theme-neptu-blog) for documentation and installation instructions.
