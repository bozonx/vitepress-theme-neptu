# Темизация

У темы **две независимые оси**:

| Ось | Атрибут | Что меняет |
|-----|---------|------------|
| Цвет | `data-theme` | Палитру: бренд-цвет, серые, подложки |
| Стиль | `data-ln-style` | Форму, плотность, типографику, анимации |

Они комбинируются свободно: `teal` + `brutal` — совсем другой сайт, чем `teal` +
`soft`, при том же контенте и тех же компонентах. Обе оси сохраняются в
`localStorage` и восстанавливаются до первой отрисовки, поэтому мигания темы
нет.

Встроенные цветовые темы: `blue`, `green`, `purple`, `amber`, `teal`, `rose`,
`magenta`, `monochrome` — те же палитры, что в блог-теме, так что лендинг и блог
на одном домене выглядят согласованно.

Встроенные стилевые пресеты: `soft` (по умолчанию), `sharp`, `brutal`, `glass`,
`editorial`.

Значения по умолчанию задаются в конфиге:

```ts
themeConfig: {
  defaultColorTheme: 'teal',
  defaultLandingStyle: 'editorial',
}
```

Попробуйте два переключателя в шапке этого сайта — вся главная перекрашивается
без перезагрузки.

## Слои токенов

```
примитивы палитры       --gray-50…950, --primary-btn-bg        ← цветовая тема
        ↓
семантические токены    --ln-c-*, --ln-radius-*, --ln-section-py…
        ↓
блоки                   scoped CSS, который читает только --ln-*
```

Блоки никогда не обращаются к «сырым» цветам и примитивам палитры — только к
`--ln-*`. Именно это правило позволяет заменить тему одним файлом стилей.

Группы токенов: цвета (`--ln-c-*`), форма (`--ln-radius-*`,
`--ln-border-width`), тени (`--ln-shadow-*`), раскладка (`--ln-container*`,
`--ln-section-py*`, `--ln-gap*`, `--ln-page-px`), типографика (`--ln-font-*`,
`--ln-h1-size`, `--ln-heading-*`, `--ln-body-lh`), анимации (`--ln-ease`,
`--ln-duration`, `--ln-lift`), кнопки (`--ln-btn-*`) и карточки
(`--ln-card-*`).

## Точечные правки

Переопределяйте токены в своём файле стилей — компоненты трогать не нужно:

```css
:root {
  --ln-container: 1200px;
  --ln-radius-lg: 0.5rem;
  --ln-font-display: 'Manrope', sans-serif;
}
```

## Своя цветовая тема

Цветовой пресет задаёт только примитивы палитры:

```css
[data-theme='ocean'] {
  --primary-hue: 195;
  --layout-hue: 210;
  --primary-btn-bg: hsl(var(--primary-hue), 72%, 42%);
  --primary-btn-bg-active: hsl(var(--primary-hue), 78%, 32%);
  /* --gray-50 … --gray-950 — скопируйте встроенный пресет и сдвиньте hue */
}
```

Дальше либо `defaultColorTheme: 'ocean'`, либо выставляйте атрибут сами.

## Свой стилевой пресет

Стилевой пресет меняет форму, плотность и анимации — но не цвета:

```css
[data-ln-style='compact'] {
  --ln-radius-lg: 0.5rem;
  --ln-section-py: clamp(2.5rem, 1.5rem + 3vw, 4.5rem);
  --ln-card-padding: 1rem;
  --ln-heading-weight: 600;
  --ln-card-shadow: none;
}
```

Оба примера лежат в `.vitepress/theme/styles.css` этого демо-сайта.

## Тёмная тема

Тёмная тема приходит из дефолтной темы VitePress (класс `.dark` на `<html>`).
Слой токенов описывает тёмные значения всех семантических переменных, поэтому
блоки и ваши пресеты подхватывают её автоматически — отдельные тёмные значения
нужны, только если пресет меняет цвета.

## Мост в VitePress

`vitepress-bridge.css` прокидывает токены лендинга в `--vp-*` — поэтому шапка,
сайдбар документации и текстовые страницы следуют той же теме, что и блоки.
Если пишете свои компоненты, используйте `--ln-*`, и они впишутся везде.
