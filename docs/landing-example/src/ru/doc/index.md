# Введение

**Neptu Landing** — это лендинг-темплейт для VitePress, построенный на базе темплейта блога Neptu.

## Возможности

- **SEO-first**: Open Graph, JSON-LD, canonical links, hreflang, sitemap
- **i18n-ready**: мультиязычная поддержка через YAML-конфигурацию
- **Полная типизация**: TypeScript для конфигурации, layouts и компонентов
- **Tailwind CSS**: встроенная поддержка через @tailwindcss/vite
- **Pagefind Search**: локальный поиск по сайту
