# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, email **ipkozyrin@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive a response within 48 hours. Please do not disclose the issue publicly until a fix is released.

## Scope

This policy covers the following npm packages published from this repository:

- `vitepress-theme-neptu`
- `vitepress-theme-neptu-landing`

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.20.x  | ✅        |
| < 0.20  | ❌        |
