Автор фигурирует в следующих местах:

- В футере поста выводится автор поста по `authorId`, указанным в frontmatter поста
- На странице списка авторов, выводятся карточки авторов, а на странице самого автора отображается его список постов
- **`twitter:creator`** — из `twitterHandle` автора. Помогает Twitter/X
  связывать статью с автором в карточках-превью.
- **`article:author`** — Open Graph-тег с абсолютным URL страницы автора.
- **JSON-LD `Person`** — структурированные данные на странице автора: имя,
  описание, портрет (`ImageObject`), ссылки (`sameAs`) и URL.
- **JSON-LD `article.author`** — объект `Person` (имя + URL) в структурированных
  данных статьи.

## Как добавить автора

## Авторы для всех локалей (`site.yaml`)

Вы можете добавить авторов для всех локалей сразу в файле `src/site.yaml`.

```yaml
# src/site.yaml
themeConfig:
  authors:
    - id: 'jhon-doe'
      name: 'Jhon Doe'
      description: 'Main correspondent'
      image: 'https://…/avatar.jpg'
      links:
        - type: 'github'
          url: 'https://github.com/…'
          title: 'GitHub'
```

Так же вы можете добавить авторов для конкретной локали или переопределить некоторые поля глобальных авторов, например имя и описание в файле `src/ru/_authors.yaml`.

```yaml
# в src/ru/_authors.yaml
- id: 'jhon-doe'
  name: 'Jhon Doe'
  description: 'Главный корреспондент'
```

И наконец в frontmatter поста указывайте id автора:

```yaml
# в frontmatter поста
authorId: ivan-k
```

## Все поля автора

Обязателен только `id`, остальные поля опциональны.

- **`id`** *(строка, обязательно)* — уникальный стабильный идентификатор. Используется в frontmatter поста (`authorId`) и для слияния записей между слоями конфигурации.
- **`name`** *(строка)* — отображаемое имя автора на странице автора и в метаданных поста.
- **`description`** *(строка)* — краткая биография. Рендерится как HTML — поддерживает Markdown-разметку.
- **`image`** *(строка)* — URL портрета автора. Используется на странице автора и в карточке автора в футере поста.
- **`imageWidth`** *(число)* — ширина `image` в пикселях для атрибута `width` тега `<img>`. Рекомендуется для предотвращения сдвига макета (CLS). Определяется автоматически для локальных файлов, но для URL нужно задать вручную.
- **`imageHeight`** *(число)* — высота `image` в пикселях для атрибута `height` тега `<img>`. Аналогично `imageWidth`.
- **`twitterHandle`** *(строка)* — имя пользователя Twitter/X без ведущего `@`. Используется для мета-тега `twitter:creator`.
- **`links`** *(массив объектов)* — социальные и внешние ссылки, отображаются под описанием автора в виде иконок. Каждая ссылка:
  - **`type`** *(строка)* — тип ссылки, определяет иконку. Встроенные: `site`, `youtube`, `x`, `facebook`, `instagram`, `tiktok`, `vk`, `mastodon`, `diaspora`. Любой другой тип (например, `github`) — универсальная иконка-глобус.
  - **`url`** *(строка)* — полный URL внешнего ресурса.
  - **`title`** *(строка)* — доступная подпись / всплывающая подсказка.

### Шаблонные подстановки

Поля автора поддерживают шаблонные переменные `${theme.*}`, `${config.*}` и
`${t.*}` — те же, что и в `_site.yaml`. Подстановки применяются после слияния
всех слоёв конфигурации.

Например, вы задали собственное поле `organizationName` в `themeConfig`:

```yaml
# src/site.yaml
themeConfig:
  organizationName: 'Neptu Blog'
```

Теперь можно подставить его в описание автора через `${theme.organizationName}`:

```yaml
# src/ru/_authors.yaml
- id: 'ivan-k'
  name: 'Ivan K.'
  description: 'Editor at ${theme.organizationName}'
```

После подстановки описание автора станет: «Editor at Neptu Blog».

## Как добавить список авторов и страницу автора

Тема автоматически строит несколько страниц, связанных с авторами:

- **`authors/`** — страница со списком всех авторов и их карточками.
- **`authors/<id>/`** — страница конкретного автора со списком его постов
  (хронологическая сортировка).
- **`authors/<id>/popular/`** — страница популярных постов автора
  (сортировка по популярности).

Чтобы вывести секцию авторов в сайдбаре, включите её в конфигурации локали:

```yaml
# src/<локаль>/_site.yaml
themeConfig:
  sidebar:
    authors: true
  # иконка секции авторов в сайдбаре (по умолчанию — встроенная)
  authorsIcon: 'lucide/users'
```

Так же убедитесь что директория `src/<локаль>/authors/` существует в вашем проекте, и вы ее не удалили. Она изначально присутствует в шаблоне блога.
