Это руководство по проекту **Neptu blog** запущено на нем самом, что позволяет вам помимо чтения документации, так же ознакомиться со всеми возможностями этого проекта.

Neptu blog является темой для VitePress и предоставляет возможность создавать статические блоги, которые в сбилженом состоянии представляют из себя обычные HTML, JS и CSS файлы.

Создать свой блог и запустить его, необычайно просто:

## Шаг 1. Скопируйте шаблон

В репозитории темы есть готовый стартовый проект — папка `template/`. Это и есть
установка: скопируйте её содержимое в новую папку своего блога.

```bash
git clone https://github.com/bozonx/vitepress-theme-neptu
cp -r vitepress-theme-neptu/packages/blog/template my-blog
cd my-blog
```

Внутри — минимальный, но полноценный блог: конфигурация, одна локаль и пара
демонстрационных постов.

## Шаг 2. Установите зависимости

```bash
npm install      # или: pnpm install / yarn install
```

Нужна минимальная версия Node.js **22.18** — этого требует VitePress 2.

## Шаг 3. Запустите версию для разработчика

```bash
npm run dev      # или: pnpm dev / yarn dev
```

Откройте `http://localhost:5173` — блог уже работает.

::: info
Благодаря встроенной в Vitepress поддержки hot reload
все ваши изменения в `src/` автоматически будут появляться и на открытой странице в браузере без необходимости обновлять страницу.
:::

## Шаг 4. Соберите продакшн-версию

```bash
npm run build      # или: pnpm build / yarn build
npm run preview    # или: pnpm preview / yarn preview
```

Скрипт `build` собирает статический сайт в `src/.vitepress/dist` и строит поисковый
индекс [Pagefind](search-pagefind). А скрипт `preview` поднимает локальный сервер на
`http://localhost:4173`, чтобы посмотреть итоговую сборку — именно её вы позже выложите в интернет.

## Шаг 5. Деплой

Для публикации своего блога в интернете, выполните деплой как указано на странице
[Публикация и деплой](deploy). Для упрощения процедуры, вы можете воспользоваться помощью ИИ агентов, примеры запросов к которым приведены на той же странице.

## Что дальше

Блог запущен — дальше в нём нужно разобраться. Начем со [структуры проекта](project-structure).
