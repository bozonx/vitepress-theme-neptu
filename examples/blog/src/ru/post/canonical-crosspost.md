**Каноническая ссылка (canonical)** указывает поисковым системам, какой URL является
первоисточником и основной версией страницы, предотвращая санкции за дублирование контента.

## Поведение по умолчанию

При `autoCanonical: true` (по умолчанию), в конфиге блога, каждая страница автоматически получает каноническую ссылку на саму себя, так что в большинстве случаев вам ничего делать не нужно.

Если вы отключили `autoCanonical` глобально, но хотите, чтобы *эта* страница ссылалась на саму себя, то укажите значение "self":

```yaml
canonical: "self"
```

## Кросспостинг: внешний canonical

Если вы публикуете у себя статью, которая изначально выходила в другом месте,
укажите каноническую ссылку на оригинальную публикацию — так поисковики сохранят
рейтинг за первоисточником, а вашу копию не сочтут дублем.

```yaml
# В frontmatter поста
canonical: "https://example.com/ru/articles/original-post"
```

> Используйте этот параметр при синдикации собственного контента, импорте со старого домена или перепубликации по разрешению.

## Отключение канонической ссылки для одной страницы

```yaml
seo:
  canonical: false
```

## Глобальные настройки

```yaml
# src/site.yaml
themeConfig:
  seo:
    canonical: true
    autoCanonical: true
```

Сведения о hreflang (многоязычном аналоге canonical) см. в
