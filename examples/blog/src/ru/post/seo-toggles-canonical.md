Все SEO-функции темы включены по умолчанию. Выключаются глобально в `src/site.yaml`
или для отдельной страницы во frontmatter через ключ `seo`. Здесь же —
канонические ссылки: поведение по умолчанию, кросспостинг и отключение.

## Глобальные переключатели

```yaml
# src/site.yaml
themeConfig:
  seo:
    og: true
    jsonLd: true
    hreflang: true
    canonical: true
    autoCanonical: true       # авто-canonical по умолчанию
    rss: true
    maxDescriptionLength: 300
  twitterSite: '@your_handle' # twitter:site на каждой странице
```

## Постраничное переопределение

```yaml
# Для одной страницы — во frontmatter (переопределяет глобальное)
seo:
  jsonLd: false
  og: false
```

## Канонические ссылки (canonical)

Каноническая ссылка указывает поисковым системам, какой URL является
первоисточником и основной версией страницы, предотвращая санкции за
дублирование контента.

### Поведение по умолчанию

При `autoCanonical: true` (по умолчанию) каждая страница автоматически получает
каноническую ссылку на саму себя, так что в большинстве случаев вам ничего делать
не нужно.

Если вы отключили `autoCanonical` глобально, но хотите, чтобы *эта* страница
ссылалась на саму себя, то укажите значение `self`:

```yaml
canonical: "self"
```

### Кросспостинг: внешний canonical

Если вы публикуете у себя статью, которая изначально выходила в другом месте,
укажите каноническую ссылку на оригинальную публикацию — так поисковики сохранят
рейтинг за первоисточником, а вашу копию не сочтут дублем.

```yaml
# В frontmatter поста
canonical: "https://example.com/ru/articles/original-post"
```

> Используйте этот параметр при синдикации собственного контента, импорте со старого
> домена или перепубликации по разрешению.

### Отключение для одной страницы

```yaml
seo:
  canonical: false
```

### Глобальное отключение

```yaml
# src/site.yaml
themeConfig:
  seo:
    # Выключить саму функциональность канонических ссылок в блоге
    canonical: false
    # Автоматически добавлять каноническую ссылку на саму себя, если не указано иное
    autoCanonical: true
```
